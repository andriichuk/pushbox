# Support

## Usage questions

Start with the [README](README.md), especially the sections about [previewing notifications](README.md#install-and-preview), [test sending](README.md#send-to-a-test-device), and [enablement and access](README.md#enablement-and-access).

If you are still stuck, search [existing issues](https://github.com/andriichuk/pushbox/issues). Open an issue with your question, the relevant package and framework versions, what you expected, and what happened instead. A small notification and registration example is more useful than a complete application.

## Bugs and feature requests

Use the [issue forms](https://github.com/andriichuk/pushbox/issues/new/choose). Include reproduction steps for a bug, or describe the workflow and benefit of a feature request.

For delivery problems, distinguish between a failed send, acceptance by Firebase, and a notification appearing on the device. Firebase acceptance alone does not prove device delivery. Include the redacted sending result and relevant client behavior.

Do not attach Firebase service account files, real device tokens, application secrets, or unredacted production payloads. Replace private values with placeholders while preserving the structure needed to reproduce the problem.

## Security issues

Report vulnerabilities privately using the instructions in [SECURITY.md](SECURITY.md). Do not disclose an exploit in a public issue.
